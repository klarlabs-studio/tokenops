This discovery-era feature backlog is retired and is not an active roadmap.
Its proposals have shipped, changed, or been superseded; older detail remains
available in Git history.

Use [`docs/adr/0004-ai-work-intelligence-and-control.md`](adr/0004-ai-work-intelligence-and-control.md)
for current product intent, phase status, and validation gates. Use `roady

surfaces are CLI, MCP, and the local API. Production evidence must come from
real work and observed outcomes, not seeded or inferred activity.
