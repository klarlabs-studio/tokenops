# Historical launch plan (v0.8.x)

This file formerly contained a time-bound launch checklist and sample MCP
responses. It is retained only because historical changelog entries link here;
none of its scripts, targets, sample output, or instructions are current.

TokenOps no longer ships a demo command or seeds synthetic product data. Do not
use example cards as evidence of current behavior. The browser dashboard was
removed in PR #387; the supported product surfaces are CLI, MCP, and the local
API.

For current product intent and roadmap status, see
